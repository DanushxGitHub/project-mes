Project overview

About AUTISO

AUTISO (AI-Assisted Autism Behaviour & Screening Analysis) is an educational machine-learning project that turns a widely used screening questionnaire into an interactive web experience.

The data behind the model

Training uses the public Kaggle autism-screening dataset: {{ meta.stats.rows }} labelled records combining ten AQ-10 behavioural indicators with demographic and historical attributes.

Exploratory analysis

Distributions, class imbalance and correlations were studied before modelling.

Cleaning & encoding

Redundant identifiers removed, rare categories merged, outliers capped, labels encoded.

Balancing

SMOTE oversampling removed the strong class imbalance in ASD-positive cases.

Model tuning

Three classifiers compared with five-fold cross-validation and randomised hyperparameter search.

Model comparison

All models were trained on the same balanced data and evaluated on a held-out 20% test set.

Ethical considerations

Automated screening tools carry risk when misused. AUTISO is designed to support — never replace — professional judgement. Results depend on honest self-reporting and on data that may not represent every population equally. Any concerning result should lead to a conversation with a qualified clinician, not to a self-diagnosis.
