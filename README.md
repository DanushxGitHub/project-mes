# AUTISO — AI-Assisted Autism Behaviour & Screening Analysis

A machine-learning web application that analyses AQ-10 questionnaire responses and
background factors to provide preliminary autism screening support.

**Disclaimer:** This tool provides screening support only — it is not a medical diagnosis.
